COMO SUBIRLO A GITHUB (nuevo repo, mas simple que el anterior)
------------------------------------------------------------------
1. Crear un repo nuevo en GitHub (ej: "ces-web" o similar). No hace
   falta clonar el viejo de TanStack, este es completamente aparte.
2. Copiar estos 7 archivos a la raiz del repo.
3. Commit + push.
4. En Netlify: "Add new site" -> conectar este repo nuevo.
   Build settings: dejar el comando de build VACIO (no hace falta
   ninguno) y "Publish directory" en "." (la raiz). El netlify.toml
   ya incluido configura esto automaticamente, Netlify deberia
   detectarlo solo.
5. Deploy. No deberia fallar nada: no hay build, no hay Nitro, no hay
   funciones - es HTML/CSS/JS servido tal cual.
